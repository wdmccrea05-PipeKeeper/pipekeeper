# PipeKeeper

PipeKeeper is a web application for pipe smokers to catalog, track, and manage their pipe and tobacco collections.

## Features

- **Pipe Collection** – Catalog your pipes with photos, maker details, measurements, and condition tracking
- **Tobacco Cellar** – Track tobacco blends, quantities, aging, and tasting notes
- **Smoking Logs** – Record smoking sessions, pipe/tobacco pairings, and ratings
- **AI-Powered Tools** – Pipe identification, value lookup, pairing recommendations, and collection optimization
- **Reports & Export** – Generate PDF and CSV reports for insurance, inventory, and statistics
- **Community** – Connect with other pipe enthusiasts, share collections, and message friends
- **Subscription Tiers** – Free, Premium, and Pro plans with progressive feature access

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS, shadcn/ui, TanStack Query
- **Backend:** Base44 platform (Deno serverless functions)
- **Payments:** Stripe + Apple In-App Purchase
- **i18n:** Custom safe-translation wrapper with multi-language support
